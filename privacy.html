Política de Privacidade

Este bot pode coletar apenas os dados necessários para seu funcionamento.

Dados coletados

  • ID de usuários
  • ID de servidores
  • ID de canais

Uso dos dados

Os dados são utilizados exclusivamente para o funcionamento do bot.

Compartilhamento

Nenhum dado é vendido ou compartilhado com terceiros.

Contato

Caso queira solicitar a remoção de dados, entre em contato pelo Discord.
